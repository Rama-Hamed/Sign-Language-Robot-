# 🤖 Sign Language Translation Robot
A cognitive robotics project developed using Webots and Q-Learning to translate sign language gestures into text.

## 🛠 Tech Stack
- Simulator: Webots
- Language: Python
- Algorithm: Q-Learning (Reinforcement Learning)

## 💡 Key Features
- Sensor Mapping: Integrated 8 distance sensors for obstacle detection and environment interaction.
- Learning Logic: Implemented reinforcement learning with custom reward functions to train the robot's movement.
- Autonomous Navigation: Designed the controller to operate within a simulated robotics environment.

## 📂 Project Structure
- controller.py: The main logic for the robot's movement and learning.
- world_file.wbt: The simulated robotics environment.
